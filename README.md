# Nexo Cirúrgico — v1.4.5

Plataforma de estudo prático de procedimentos médicos para alunos e médicos em treinamento. Seletor PT/ES funcional, sem aviso nem bloqueio de aprovação externa para estudo.

Tradução editorial: menus, títulos das 115 aulas, 46 nomes e resumos das fichas práticas, nomes de módulos e interface. **As seções completas dos procedimentos, corpos das aulas e avaliações permanecem parcialmente em português e serão traduzidas por etapas.** Não confundir estudo educacional com protocolo assistencial autorizado.

O pacote `project-source.tar.gz` contém todo o código e os relatórios; Vercel extrai esse pacote e publica só `dist`. Os cinco livros protegidos por direitos autorais não fazem parte do site.
