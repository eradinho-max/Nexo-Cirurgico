# Nexo Cirúrgico

Plataforma educacional de procedimentos técnicos em Medicina, destinada a estudantes e médicos em treinamento supervisionado.

## Situação

Repositório inicializado em 14/10/2026 para integração GitHub + Vercel. A migração do código-fonte da versão local **MB03 — Lote 2 (v1.4.1)** ainda está pendente. **Este repositório ainda não contém a aplicação nem deve ser tratado como um deploy funcional.**

## Arquitetura prevista

Aplicação estática HTML/CSS/JavaScript, `npm run build`, publicação do diretório `dist` na Vercel, com revisão clínica independente antes da disponibilização de instruções como conteúdo validado.

## Entregas e qualidade

Preservar 33 trilhas e 115 aulas históricas, realizar regressão a cada macrobloco e gerar backup ZIP completo. Os materiais e procedimentos permanecem em revisão editorial até validação clínica.
